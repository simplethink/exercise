| 参数名   | 类型   | 必选 | 示例值                | 校验规则                     |
|----------|--------|------|-----------------------|------------------------------|
| username | string | 是   | "zhangsan"            | 长度 3-20，仅字母数字        |
| password | string | 是   | "Pass1234!"           | 至少 8 位，含大小写+特殊字符 |
| contact  | object | 否   | `{email: "a@b.com"}`  | 邮箱/手机号二选一            |
